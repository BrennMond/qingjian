# 受审依赖白名单（PLAN §4.8 / D9）
#
# 格式（空白分隔，每行一条）：
#
#     <crate 名>  <精确版本>  <SPDX 许可>  <为什么允许它的理由>
#
# 规则由 scripts/verify-deps.sh 执行：
#   1. Cargo.lock 里**每一个来自 registry 的包**都必须在这里出现，且版本一致；
#   2. 名单里不许有已经不在 Cargo.lock 里的**陈旧条目**（否则名单会变成历史垃圾堆）；
#   3. 同一个 crate 出现多个版本直接失败（重复依赖会让二进制变大、许可变复杂）。
#
# 现在这份名单是**空的**——这不是遗漏，而是事实：
# 整个 workspace 目前零第三方依赖（见 verify-zero-deps.sh）。
# 空名单让门禁的"第一次违规"发生在真正引入依赖的那一刻，
# 而那正是需要有人（而不是脚本）做决定的时候。
#
